# Некоторые функции агрегации, используемые при группировке ($group)

В операторе $group используются агрегирующие функции, которые позволяют выполнять вычисления на основе данных в группе. 

| **Функция**        | **Описание**                                                         | **Пример использования**           |
|--------------------|----------------------------------------------------------------------|------------------------------------|
| `$sum`             | Суммирует значения в группе.                                         | `{ $sum: "$price" }`               |
| `$avg`             | Вычисляет среднее арифметическое значений в группе.                  | `{ $avg: "$score" }`               |
| `$min`             | Находит минимальное значение в группе.                               | `{ $min: "$age" }`                 |
| `$max`             | Находит максимальное значение в группе.                              | `{ $max: "$age" }`                 |
| `$first`           | Возвращает первый документ в группе.                                 | `{ $first: "$name" }`              |
| `$last`            | Возвращает последний документ в группе.                              | `{ $last: "$name" }`               |
| `$push`            | Создаёт массив из всех значений в группе.                            | `{ $push: "$tags" }`               |
| `$addToSet`        | Создаёт массив уникальных значений (без дублирования).               | `{ $addToSet: "$category" }`       |
| `$arrayElemAt`     | Извлекает значение из массива (здесь: из массива `tags` 1-й элемент) | `{ $arrayElemAt: [ "$tags", 0 ] }` |
| `$count`           | Считает количество документов в группе (суммирует 1).                | `{ $sum: 1 }`                      |
| `$mergeObjects`    | Объединяет несколько документов в один объект.                       | `{ $mergeObjects: "$details" }`    |
| `$stdDevPop`       | Вычисляет стандартное отклонение для всех значений (популяционное).  | `{ $stdDevPop: "$values" }`        |
| `$stdDevSamp`      | Вычисляет стандартное отклонение (выборочное).                       | `{ $stdDevSamp: "$values" }`       |



*Пример: Группировка с вычислениями*
*Исходные данные*
```
[
  { "_id": 1, "category": "A", "price": 100 },
  { "_id": 2, "category": "A", "price": 200 },
  { "_id": 3, "category": "B", "price": 300 },
  { "_id": 4, "category": "B", "price": 400 }
]
```

*Запрос с `$group`*
```
db.collection.aggregate([
  {
    $group: {
      _id: "$category",             // Группировка по полю "category"
      totalPrice: { $sum: "$price" }, // Сумма цен в каждой группе
      avgPrice: { $avg: "$price" },  // Средняя цена в группе
      minPrice: { $min: "$price" },  // Минимальная цена
      maxPrice: { $max: "$price" },  // Максимальная цена
      count: { $sum: 1 }             // Количество документов
    }
  }
])
```

*Результат:*
```
[
  { "_id": "A", "totalPrice": 300, "avgPrice": 150, "minPrice": 100, "maxPrice": 200, "count": 2 },
  { "_id": "B", "totalPrice": 700, "avgPrice": 350, "minPrice": 300, "maxPrice": 400, "count": 2 }
]
```


### В MongoDB агрегация возможна и без стадии `$group`

`$group` — это только одна из стадий aggregation pipeline.  
Полезна, когда требуется сгруппировать документы и вычислить агрегатные значения (сумму, среднее, количество и т.д.).

Агрегация может успешно работать и без `$group`.  
Например, в стадии `$project` или `$addFields` мы можем выделить из массива необходимый нам элемент

**Пример без `$group` (из БД `Atlas > sample_restaurants > restaurants`):**

```js
db.collection.aggregate([
  { $addFields: {
      first_grade: { $arrayElemAt: ["$grades", 0] }
  }}
])
```

В результате агрегации появляется новое поле `first_grade` со значением первого элемента массива `grades`.

### Сравнение

| Способ                         | Контекст   | Что возвращает                            |
| ------------------------------ | ---------- | ----------------------------------------- |
| `$arrayElemAt: ['$grades', 0]` | expression | Первый элемент массива                    |
| `$slice: ['$grades', 1]`       | expression | Массив с первым элементом                 |
| `$first: '$grades'`            | expression | Первый элемент массива                    |
| `$first: '$grades'`            | `$group`   | Значение поля из первого документа группы |



### ⚠️ Важное уточнение: `$first` работает в разных контекстах по-разному.

#### 1. В `$group`:
```
{
  $group: {
    _id: null,
    firstGrade: { $first: "$grades" }
  }
}
```

Здесь `$first` берёт **весь** массив `grades` из **первого документа группы**.  

Результат: один-единственный документ коллекции с полем `firstGrade`, равным значению **всего** массива из первого документа.

#### 2. В выражениях (expression context) некоторых стадий (`$project`, `$addFields` и т.д.):

```
{
  $project: {
    firstGrade: {
      $first: "$grades"
    }
  }
}
```

Здесь `$first` берёт **первый элемент массива** в **каждом документе**.

Результат: все документы коллекции с одним полем `firstGrade`, равным значению **только первого** элемента массива.
